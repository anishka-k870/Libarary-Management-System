PROJECT TITLE
Library Management System

STUDENT NAME
Anishka Kumari

OBJECTIVE
To develop a simple Library Management System using Java and Object-Oriented Programming concepts.

PROBLEM STATEMENT
Managing books manually in a library can be difficult. This system helps users view, search, borrow, and return books efficiently.

OOP CONCEPTS USED
1. Class
2. Object
3. Constructor
4. Methods

CLASSES USED

1. books
   - Stores book details such as ID, title, author, and availability.

2. library
   - Manages all books.
   - Provides search, borrow, return, display, and summary features.

3. Main
   - Contains the main method and menu-driven program.

ARRAYS USED
A books array is used to store multiple book objects.

STRINGS USED
Strings are used to store book titles, author names, and user search input.

MENU OPTIONS
1. Display all Books
2. Search Book
3. Borrow a Book
4. Return a Book
5. Show Library Summary
0. Exit

SAMPLE INPUT AND OUTPUT

Input:
1

Output:
Displays all books with their details.

Input:
2
1984

Output:
Book Found

CHALLENGES FACED
1. Understanding constructors.
2. Splitting code into multiple files.
3. Fixing string comparison issues.

CONCLUSION
The project successfully demonstrates Java fundamentals such as classes, objects, constructors, arrays, strings, loops, conditions, and methods.
